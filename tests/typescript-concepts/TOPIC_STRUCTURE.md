# Topic Structure

Each numbered topic contains focused subtopic folders. Run any lesson with:

```powershell
npx tsx ../tests/typescript-concepts/<topic>/<subtopic>/<file>.ts
```

Topics:

1. `01-fundamentals` - variables, data types, and operators.
2. `02-control-flow` - control statements, conditions, and loops.
3. `03-functions` - functions, parameters, returns, callbacks, and modules.
4. `04-collections` - arrays, objects, strings, and useful methods.
5. `05-oop` - classes, constructors, encapsulation, abstraction, inheritance, and polymorphism.
6. `06-error-handling` - try, catch, throw, and finally.
7. `07-logical-programming` - practical coding exercises.
8. `08-async-and-promises` - asynchronous JavaScript required by Playwright.
9. `09-playwright-foundations` - tests, locators, actions, assertions, dialogs, and page objects.
10. `10-json-and-api-basics` - JSON data and API-response concepts for API testing.
